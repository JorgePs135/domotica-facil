Automatizaciones de Home Assistant sin pelearte con el YAML

Rellena un formulario con tus entidades y obtén una automatización lista para pegar, con la sintaxis actual, explicada paso a paso y con lo que necesitas tener configurado.

Abrir el generadorVer tutoriales

Funciona en tu navegador: no se envía ni se guarda nada de lo que escribes.

Cómo funciona

  1. Paso 1: Elige y rellena

    Escoge una plantilla y escribe tus entidades (las copias de Herramientas para desarrolladores → Estados).

  2. Paso 2: Copia el YAML

    El código aparece al momento, con la sintaxis actual. Cópialo o descárgalo como archivo .yaml.

  3. Paso 3: Pégalo y compruébalo

    Debajo del código tienes los pasos para añadirlo a Home Assistant y cómo ver si funciona.

Qué puedes generar

  • Plantilla A

    Luz con sensor de movimiento

    Enciende una luz al detectar movimiento y la apaga cuando deja de haberlo.

  • Plantilla B

    Aviso cuando un sensor pasa de un valor

    Envía un aviso cuando un sensor numérico supera (o baja de) un límite.

  • Plantilla C

    Encender o apagar a una hora

    Enciende o apaga una luz o un enchufe a una hora fija, todos los días o solo algunos.

Por qué otro generador

  • Sintaxis vigente. Muchos ejemplos de foros usan platform: y service:. El generador usa la sintaxis actual (trigger:, action:) y cada plantilla se valida con Home Assistant 2026.10.
  • Sin sorpresas. El código sale de plantillas fijas y revisadas, no de una IA: los mismos datos dan siempre el mismo resultado.
  • Te dice lo que falta. Requisitos, integraciones necesarias, advertencias y enlaces a la documentación oficial de cada parte.
  • En español y sin cuentas. Pensado para quien empieza, sin anuncios ni seguimiento.
